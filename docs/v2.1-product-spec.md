## Disk rule (hard)

Per-tree / per-pixel / per-5 m data → `_light_v2.gpkg` on Zenodo only. JSON + `kg_v2_store`
get fixed-size 25 m indexes, ≤ 25 KB/KG. No per-tree rows in `search_index.db`, no polygons in
JSON, no new per-parcel index columns. Primary `json/` is 22 GB @ 3464 KGs; v2 ingest is the
disk fix — 2.1 must not undo it.

## Formats

**`terrain.grid25`**: `{cell_m:25, cols, rows, origin:"nw", crs:"EPSG:3035", x0, y0, unit:"dm",
base_dm, coding:"delta_i16"|"i32", elev:<b64 gz>, valid?:<b64 gz packbits (only if not all
valid)>, slope:<b64 gz uint8 deg, 255 nodata>, n_valid}`. Grid = union of the 25 m-snapped
(bbox-overshooting) tile rectangles, so it *covers* the bbox with ≤1.7 km slack per side.
Decode: `v21_products.decode_terrain_grid25`.

**`landcover.grid25`**: same grid; `coding:"u8"`, `cls:<b64 gz uint8 type_code>` (0 = none),
`cover_frac:<b64 gz uint8 0..255>`, `legend:{code:type}`, `n_classified`. Decode:
`decode_landcover_grid25`.

**`acquisition`**: `{tiles:[{tile, dtm_year, dsm_year, ortho_year, eff_date, years_gap}],
summary:{n_tiles,n_known,als_year_min/max,years_gap_median,source}}` (codec table path).

**`_light_v2.gpkg`**: `tree_apices` points EPSG:3035 + R-tree (GDAL default), columns
`tree_id, h_m, crown_r_m, crown_area_m2, detection_source, detection_conf, surface_class,
tree_likelihood, stand_context (tree/orchard/vineyard/hedge/garden/shrub/other/none),
segment_type, segment_type_conf, dh_per_year_m, als_year, ndvi, leaf_type_hint,
leaf_type_conf, dbh_est_cm, volume_m3_est`; `terrain_coarse_{dtm,dsm,ndsm,slope,aspect}`
single-band **float32** 5 m (m / deg, nodata −9999 — int16 dropped: GDAL reads Int16 GPKG
coverage nodata back as +32768).

Apex inventory: `tree_inventory.build_inventory` **ndsm_only** on the stitched nDSM (only
where a v2 segment exists), 2048 px chunks + 48 px halo (apex-in-core), cadastre footprints
as `building_mask`; ndvi/dh point-sampled from tile rasters. No fused mode: the processor and
the full-GPKG `Ortho_*` only hold 1 m ortho (fused seeding needs ≤0.5 m).

## Verify checks

`product_version` (fatal) · `grid25_present` (warn — monster KGs) · `grid25_decodes`,
`grid25_dims` (covers bbox, ≤1.7 km slack), `grid25_finite` (≥40 % cells), `grid25_range`
(±50 m fatal, ±5 m `_drift` warn), `landcover_grid25_dims` (fatal when present) ·
`tree_stats_v21` (warn) · `terrain_coarse_layers` (fatal iff grid25 present) ·
`apices_layer` (fatal iff JSON claims `apices_layer:"tree_apices"`; count ±20 %, R-tree).
